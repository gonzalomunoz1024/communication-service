## Addendum: O-2c
Not a script artefact. Reproduced and measured in 35-frozen-db-ab.txt (three freeze rounds, 108 calls per jar): with
mongod frozen and more than one call in flight, the driver pauses its pool (MongoConnectionPoolClearedException, which
Spring Data MongoDB 5.0.8 translates to UncategorizedMongoDbException); GlobalExceptionHandler.isDatabaseUnavailable
(GlobalExceptionHandler.java:70-72) does not recognise it, so handleGeneric (:184-188) answers 500 with the driver's
message, which names the server address. Iteration 3 answers the same 500s on the plain endpoints (A/B). GAP-backend4-1.
