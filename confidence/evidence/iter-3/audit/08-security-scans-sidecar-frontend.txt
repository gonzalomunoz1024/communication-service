== 3. Reachability, by code read (govulncheck's call-graph check cannot run here)
- CVE-2026-111943 crypto/x509 (Verify rejects known distrusted intermediates): REACHABLE. The report client is a TLS client with verification on by
  default (sidecar/internal/report/client.go:65-89: tls.Config{MinVersion TLS1.2}, optional CS_CA_FILE pool, InsecureSkipVerify only on opt-in), so every
  https CS_ENDPOINT handshake calls x509 Verify. Red Hat rates it 3/HIGH (CVSS 6.8, AC:H/UI:R).
- CVE-2026-78667 net/http Range header: not reached (no ServeContent/ServeFile/FileServer in sidecar/cmd or internal).
- CVE-2026-78669 HTTP/2 SETTINGS: not reached as far as the code shows (client Transport sets TLSClientConfig without ForceAttemptHTTP2, so HTTP/2
  is off; the status server is plain HTTP/1.1, cmd/health-sidecar/main.go:55-57).
- CVE-2026-97031 crypto/tls ECH (server side): not reached (the sidecar runs no TLS server).
So CI's own govulncheck step would report at least the x509 entry once vuln.go.dev is reachable (not run: blocked here).
